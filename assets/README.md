# Shared Assets

This folder is intentionally minimal.

Do not add large asset libraries just to make the repository feel complete. Add only assets that are actually used by Captionflow motion projects.

Preferred order:
1. recreate simple UI/vector elements in code
2. use existing local Captionflow assets when available and appropriate
3. add a specific external media asset only when the concept requires it

Keep filenames descriptive and reusable. Avoid duplicated exports and unnecessary variants.
