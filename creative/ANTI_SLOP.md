# Anti-Slop Rules

This exists to prevent technically impressive but visually generic AI-generated motion.

## Remove immediately if present

- meaningless glass cards
- random glowing orbs
- excessive particle fields
- generic AI sparkles
- floating dashboard statistics that do not exist in the product
- fake charts
- fake testimonials
- random numbers used as decoration
- oversized gradient blobs competing with the subject
- repeated purple-blue gradient on every object
- excessive drop shadows
- unnecessary 3D rotation
- unreadably small desktop UI
- type entering one word at a time for every sentence
- five different animation styles in one piece
- empty phrases such as “Future of editing”, “Powered by AI”, “Work smarter”, “Next-level content”

## Repetition test

Before finalizing, inspect consecutive scenes.

If two beats use the same:
- card layout
- zoom behavior
- text reveal
- camera move
- transition
- gradient treatment

change one of them unless repetition is a deliberate motif.

## Necessity test

For every object, ask:

**Does this communicate, guide attention, create continuity or strengthen Captionflow identity?**

If not, remove it.

## Authenticity test

A frame should not be considered successful just because it looks polished.

It should feel plausible as work commissioned by Captionflow.

If the same frame could be rebranded to any random AI SaaS by changing the logo and accent color, it is too generic.

## Copy test

Delete:
- redundant explanations
- feature lists inside motion scenes
- long descriptions
- repeated claims
- words that simply narrate an obvious click

Prefer concrete contrast and visual proof.

## Complexity test

Advanced motion does not mean more elements.

Advanced motion means:
- better continuity
- better timing
- better masking
- better spatial reasoning
- better hierarchy
- better interaction between typography and product

## Final standard

The output should feel designed, not generated.
