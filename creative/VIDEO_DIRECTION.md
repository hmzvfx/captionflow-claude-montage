# Video Direction

This file defines how a Captionflow short-form motion piece should communicate.

## Objective

Create videos that are immediately understandable, visually advanced and commercially useful without feeling like conventional ads.

The viewer should feel the improvement before being told about it.

## Narrative principle

Use this order when appropriate:

**problem → friction → transformation → result**

But do not treat it as a mandatory four-scene template. The transformation can happen in one continuous visual idea.

## First second

The opening should contain at least one of:
- a visual contradiction
- a strong UI transformation
- a direct problem statement
- an unexpected product-scale movement
- an obvious before/after contrast

Do not open with a logo animation unless the concept specifically requires it.

## Copy

Copy should be minimal and natural.

Preferred:
- 2–7 words for a primary line
- one idea at a time
- concrete language
- language that describes the user's situation or outcome

Avoid:
- marketing filler
- 'revolutionize your workflow'
- 'unlock the power of AI'
- 'create like never before'
- excessive adjectives
- restating the UI action as narration

## Tone

Fast. Precise. Confident. Understandable.

Not:
- loud
- hyperactive
- corporate
- motivational
- futuristic for the sake of it

## Product storytelling

Show cause and effect.

Examples:
- raw clip enters → transcript resolves → caption treatment appears → export resolves
- five disconnected tools collapse into one Captionflow workspace
- manual B-roll search fragments the frame → Captionflow reorganizes it into one controlled flow
- a flat transcript becomes expressive captions through a single interaction

The user benefit must be visible.

## Scene design

Every scene needs a clear focal point.

Use negative space. On a phone, one strong object is often more effective than six medium-sized objects.

Do not fill the vertical frame simply because space exists.

## Rhythm

Use contrast:
- fast transition → readable hold
- macro UI → close detail
- dark quiet frame → bright active state
- dense workflow → simple final result

Avoid equal timing for every scene. Mechanical repetition makes the work feel generated.

## Branding

The Captionflow name or mark does not need to dominate every piece.

Brand recognition should primarily come from:
- visual language
- UI
- color
- motion
- typography

A concise Captionflow end state is usually enough.

## End frame

Resolve the story.

Possible endings:
- finished video/export state
- clean product hero
- compact promise
- Captionflow name + one understated action

Avoid long CTA screens or lists of features.

## Variation across a content library

Do not make ten videos that all look like one template.

Rotate creative modes:
- cinematic product UI
- kinetic typography + UI
- workflow compression
- before/after transformation
- object metaphor
- timeline choreography
- product macro detail
- feature reveal

The brand stays constant; the concept changes.
