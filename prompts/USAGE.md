# Prompt Usage

The repository carries permanent art direction. Individual prompts should therefore stay focused on the **idea**, not restate the whole design system.

## A good video prompt should supply

- the communication goal
- the audience/problem
- the core hook or idea
- any product feature that must appear
- approximate duration if important
- required copy, if any
- any footage/assets that must be used

Then explicitly tell Claude to use the repository creative system and retain creative freedom over execution.

## Do not overload prompts with

- exact hex values already stored here
- every transition
- every scene duration
- every camera move
- long lists of visual effects
- repeated instructions to make it modern/premium

Those constraints usually reduce the quality of the design.

## Recommended working behavior

Claude should:
1. read the creative system
2. inspect the existing project before editing
3. propose the strongest motion concept internally
4. implement the video
5. preview/check key frames
6. refine obvious weak or generic sections
7. leave the project renderable and organized

The user should not need to manually rebuild the project after Claude finishes.
