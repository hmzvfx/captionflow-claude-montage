# Video Projects

Claude should create one self-contained folder per video concept inside this directory.

Example:

`videos/001-one-video-five-tools/`

A video folder may contain its own Remotion project or a composition/module inside a shared implementation if that becomes technically cleaner later. Choose the simplest structure that keeps each piece easy to edit and render.

Naming:
- numeric prefix for ordering
- short kebab-case concept name
- do not name projects `final-final-v2`

Each project should be left in a renderable state with a short local README only when setup or render commands are not obvious from the code.

Do not copy the entire creative system into video folders. Reference the root creative files instead.
